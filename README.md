# 天道玄机 · Heavenly Decrypt

一款基于 HarmonyOS（API 21 / 6.0.1）的传统易学文化应用，融合八字命理、六爻起卦与易理图鉴，并提供 AI 深度解析能力。

> 本项目为传统文化娱乐应用，所有内容仅供文化娱乐参考，不构成医疗、投资、法律或任何决策依据。

## 功能总览

### 生辰八字

- 四柱排盘（1900–2100，含农历与闰月换算）
- 五行分布与生克可视化（Canvas 五行循环图 + 旺相休囚死）
- 日主分析与格局判定（建禄格 / 食伤格 / 财星格 / 官杀格 / 印绶格）
- 地支藏干、纳音五行、神煞（天乙贵人、桃花、驿马、羊刃、华盖、文昌等 10+ 种）
- 大运排盘（阳男阴女顺行、起运年龄按精确节气时刻计算，6 小时折 1 个月，精确到月）与流年/月度运势
- 流年支持任选年份查看（前后箭头切换，按立春定界）
- 命宫、胎元进阶参考
- 可选真太阳时校正（按出生地东经度 + 均时差）
- 晚子时（23:00 后）换日开关，可在设置中按流派偏好切换
- 排盘记录本地持久化（保存 / 恢复 / 删除），一键复制 / 系统分享排盘结果

> **节气精度**：内置 VSOP87D 天文算法实时计算太阳黄经并二分求节气时刻，
> 节气时间误差约 1–2 分钟（已用 2000/2020 春分、2025 立春等公开数据校验）。
> 年柱以**立春**为界，月柱以**节**（立春/惊蛰/清明/立夏/芒种/小暑/立秋/白露/寒露/立冬/大雪/小寒）为界，
> 交节前后出生不再出现排盘错位。

### 周易起卦

- 四种起卦法：硬币、数字、时间、手动排爻
- 64 卦全量数据：卦辞、彖传、大象传、序卦传、爻辞、小象传、爻位分析
- 京房六爻排盘：八宫归属、纳甲纳支、六亲、世应、六兽、旬空
- 变卦 / 互卦 / 错卦 / 综卦、体用生克、动爻分析
- 月建/日辰按精确节气算法取用（与八字引擎同源，交节不串月）
- 卦名/卦辞搜索，起卦记录本地持久化，一键复制 / 系统分享卦象结果

### 易理图鉴

- 河图（五行生成数）、洛书（九宫纵横十五）
- 先天 / 后天八卦切换，八卦万物类象（五行、家庭、身体、方位）

### 黄历万年历

- 任意日期（1900–2100）公历 / 农历对照
- 干支年（立春定界）/ 月（节气定界）/ 日、生肖、当前节气、交节日提示
- 建除十二神 + 传统宜忌、冲煞方位（全部离线计算）

### 二十四节气

- 当年 24 节气精确时刻表（VSOP87D 天文算法，误差约 1–2 分钟，北京时间）
- 节气黄经、节气说明，当前所处节气高亮，支持年份切换

### 生肖运程

- 十二生肖当年运程 + 与今日干支的关系（值日 / 六合 / 三合 / 相冲 / 平平）
- 生肖配对速查（六合、三合、六冲）

### 生肖配对

- 十二生肖两两配对关系速查（六合 / 三合 / 六冲 / 相刑 / 相害 / 平平）
- 配对评分（0–100），黄绿红三色直观区分吉凶
- 生肖关系完整规则：六合 / 三合 / 六冲 / 相刑 / 相害 / 自刑

### 八字合婚

- 完整合婚评分：日干五行生克 + 日支六合三合冲害 + 生肖六合三合冲害刑 + 纳音相生相克 + 五行互补
- 分项明细与总分（0–100），附「吉 / 平 / 需磨合」结论与改善建议
- 支持双方出生日期 / 时间自由输入，离线即时计算

### 吉时查询

- 任意日期的 12 时辰吉凶表（黄黑道十二神：青龙 / 明堂 / 天刑 / 朱雀 / 金匮 / 天德 / 白虎 / 玉堂 / 天牢 / 玄武 / 司命 / 勾陈）
- 黄道吉时高亮 + 宜忌提示
- 当日最吉时辰汇总

### 今日卡片

- 首页常驻：公历 / 农历 / 干支日 / 生肖 / 节气 / 今日卦象（与日干支挂钩）

### 更多（功能总览）

- 首页主 tab 收为「八字 / 起卦 / 黄历 / 吉时 / 更多」五个，其余功能统一收纳
- 节气、生肖运程、生肖配对、八字合婚、易理图鉴、隐私与免责均在「更多」页直达

### 离线详析（无 AI 也可用）

- 八字：日主、格局、月令、五行分布与喜忌、纳音、神煞、命宫胎元、大运、流年完整文本报告
- 起卦：卦辞、彖传、大象、序卦、变卦、互错综卦、体用生克、动爻逐爻解读
- 未配置 API Key 时，AI 面板自动切换为离线详析，功能不受影响
- 全部排盘 / 合婚 / 黄历 / 吉时 / 配对逻辑本地完成，完全离线可用

### AI 大师解析

- 支持 Gemini、OpenAI、DeepSeek、通义千问、智谱 GLM、自定义 OpenAI 兼容接口
- 多轮追问、分类提问（事业 / 情感 / 财运 / 健康 / 综合）、思考加载态、上下文自动裁剪
- 离线兜底解析（未配置密钥时也可给出基础断语）
- API 密钥使用系统 Asset Store 加密存储（旧明文自动迁移），仅保存在本机；深色 / 浅色主题一键切换

## 构建与运行

环境要求：DevEco Studio 6.0+（自带 hvigor / ohpm）。

仓库内同时提供 GitHub Actions CI（`.github/workflows/build.yml`），
使用 OpenHarmony SDK 6.0 在 ubuntu 上执行依赖安装与 HAP 编译检查；
CI 使用无签名专用配置 `build-profile.ci.json5`，不会接触本地签名密钥。

```bash
# 安装依赖（首次）
ohpm install

# 构建 HAP（产物在 entry/build/default/outputs/）
hvigorw assembleHap --mode module -p product=default

# 构建整包 APP（产物在 build/outputs/default/）
hvigorw assembleApp
```

使用 DevEco Studio 打开工程，连接 HarmonyOS 设备或模拟器后运行 `entry` 模块即可。

## 签名与安装

命令行构建产物为**未签名**包（`*-unsigned.hap` / `*-unsigned.app`），
需要签名后才能安装到真机。两种方式任选其一：

### 方式一：DevEco Studio 自动签名（推荐）

1. 用 DevEco Studio 打开工程
2. 菜单 `File → Project Structure → Signing Configs`
3. 勾选 **Automatically generate signature**
4. 按提示登录华为开发者账号（首次会在 AppGallery Connect 自动创建应用并下载证书）
5. 勾选后点击 **OK**，IDE 自动回填 `build-profile.json5` 并完成签名
6. 直接点击 Run 安装到真机；或构建出已签名的 HAP 安装

### 方式二：手动签名

1. 在 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)
   创建应用（包名 `com.tiandao.xuanji`），生成调试/发布证书 `.cer` 与 Profile `.p7b`，
   并生成密钥库 `.p12`
2. 在 `File → Project Structure → Signing Configs` 手动选择三个文件并填入密码
3. 或按 `build-profile.json5` 中的注释模板直接填写路径

签名完成后，构建出的 HAP 即可直接 `hdc install` 安装到设备。

> ⚠️ **密钥安全说明**
> - `build-profile.json5` 通过 `git update-index --skip-worktree` 标记为**本地专属**，仅含占位/自动签名模板，**真实证书路径与密码不入库**。
> - 如需在本机使用手动签名，请取消 skip-worktree 并填入本机证书，**切勿将含真实密钥的文件提交或推送**。
> - 若怀疑签名密钥曾泄露，请立即在 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) **吊销并重新生成证书**，旧密钥即失效。
> - AI API 密钥使用系统 Asset Store 加密存储（见 `services/aiService.ets`），不会以明文持久化；保存失败会在界面明确提示，不会静默降级为明文。

> 注意：`build-profile.json5` 已通过 `git update-index --skip-worktree` 标记为本地专属，
> 提交到仓库的是不含密钥的占位版本；CI 构建前会自动切换为 `build-profile.ci.json5`。

## AI 配置说明

1. 点击首页右上角 ⚙ 打开设置
2. 选择模型服务商并填入 API Key（也可自定义模型名 / Base URL）
3. 排盘 / 起卦后即可发起 AI 追问

密钥使用系统 Asset Store 加密保存（仅本机），排盘数据仅在你主动发起解析时发送至所选服务商。
